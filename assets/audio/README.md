# صداها

این پوشه برای قرار دادن فایل‌های صوتی بازی است.

## ساختار پوشه‌ها

```
audio/
├── sfx/         # افکت‌های صوتی کوتاه
│   ├── button.ogg
│   ├── start_sim.ogg
│   ├── draw_line.ogg
│   ├── impact.ogg
│   ├── win.ogg
│   ├── lose.ogg
│   ├── coin.ogg
│   └── level_unlock.ogg
└── music/
    └── ambient.ogg    # موسیقی پس‌زمینه
```

## منابع رایگان صوتی با مجوز روشن

در صورت عدم امکان تولید صداه اختصاصی، این منابع با مجوز CC0 یا CC-BY مناسب هستند:

1. **Freesound** (https://freesound.org/) — فیلتر CC0
2. **OpenGameArt** (https://opengameart.org/) — فیلتر CC0
3. **Kenney.nl** (https://kenney.nl/) — همه صداها CC0

## مشخصات فایل‌ها

- **فرمت**: OGG Vorbis (باکیفیت متوسط برای حجم کم)
- **نرخ نمونه‌برداری**: 44100 Hz
- **کیفیت**: -q 4 (حدود 128 kbps)
- **مدت**: حداکثر ۱–۲ ثانیه برای SFX، ۱–۳ دقیقه برای موسیقی (با قابلیت لوپ)

## در حال حاضر

اگر فایل صوتی وجود نداشته باشد، `AudioManager` به‌صورت بی‌صدا کار می‌کند (با هشدار در کنسول). بازی بدون صدا کاملاً قابل اجرا است.

## سازهای ایرانی (اختیاری)

برای موسیقی پس‌زمینه می‌توان از سازهای زیر به‌صورت محدود استفاده کرد:
- سه‌تار (نت‌های کوتاه ملایم)
- نی (بدون اوج‌گیری)
- کمانچه (ریتم آرام)

موسیقی نباید مزاحم تمرکز بازیکن روی معما باشد.
