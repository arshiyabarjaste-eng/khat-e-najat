## نکته

این‌ها **mockup** هستند — با matplotlib و پالت رنگ پروژه ساخته شده‌اند، نه از رندر واقعی Godot. برای تولید دوباره یا اضافه‌کردن اسکرین‌شات مرحله جدید:

```bash
python3 scripts/generate_screenshots.py
```
